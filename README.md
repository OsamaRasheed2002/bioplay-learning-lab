# BEPlay

Build a beautiful, modern, interactive biomedical engineering learning platform called BioPlay.

The platform should make learning biomedical engineering fun, visual, engaging and accessible to university students.

For the initial version, create a polished homepage with:

A welcoming hero section introducing BioPlay, with the headline "Explore the Science Behind the Human Body" and a short subtitle.

A navigation bar with Home, Anatomy Explorer, Signals Lab, Medical Devices, Challenges and My Progress.

A collection of attractive learning cards for:

Anatomy Explorer

Biomedical Signals Lab

Medical Devices

Biomedical Engineering Concepts

Interactive Challenges

A learning progress section showing XP, achievements and completed topics.

Clear buttons inviting users to start learning.

Visual design:

Premium, playful and futuristic educational aesthetic.

Soft mint green, lavender, pale blue and warm off-white.

Rounded cards, subtle shadows and smooth animations.

Beautiful typography and clean spacing.

Use relevant biomedical illustrations and visual elements.

Fully responsive design for desktop, tablets and mobile phones.

Build this as a functional web application, not just a static image or mockup. Use React and TypeScript. Make the navigation and buttons interactive where possible.

For now, focus on creating an excellent homepage and the overall design system. We will build the individual learning experiences step by step.
